MessageLoggerFix

A small local black box for edits, deletions, and ghost pings. The record only knows what this client actually saw.

Get plugin source on GitHub Read the original README Review the evidence

The loot is plaintext.

Enabling capture retains message text, including words someone later edits or deletes, on this computer. Local does not mean encrypted or harmless. Get permission from the people whose messages you retain; disabling capture does not erase existing logs or exported files.

BetterDiscord’s current plugin guidelines explicitly disallow message logging and access to deleted messages. This is an independent review build, not an approved BetterDiscord addon. Account and compatibility risks remain; private review does not remove them.

What the record contains

  • Capture starts off. A separate explicit choice enables it.
  • Edits require a prior cached text snapshot and an actual content change.
  • A missing deleted message becomes an honest tombstone, not invented recovered text.
  • Direct mentions of the signed-in user identify deleted ghost pings.
  • Local search, event filters, JSON export, and confirmed clearing; four panel skins.

The plugin has no network requests, telemetry, remote assets, updater, or plugin-library dependency. This page has no scripts and does not run the plugin.

What the record cannot promise

  • No recovery of messages the client never observed while capture was active.
  • Message text is clipped to 20,000 JavaScript string units; attachments and complete chat transcripts are not archived.
  • Defaults retain up to 1,000 events and 1,000 cached snapshots for 30 days. Oldest records are pruned to a 4 MiB serialized storage budget.
  • Age pruning runs during startup, mutations, or saves; it is not a secure-erasure timer.
  • Discord’s internal event interface can change. Missing subscriptions fail closed and report capture unavailable.

Manual installation, after review

No account or application is changed by opening this page.

  1. Review the source, privacy implications, and platform restrictions above.
  2. With BetterDiscord already installed, place messageloggerfix.plugin.js in its plugins folder. On macOS: ~/Library/Application Support/BetterDiscord/plugins.
  3. Enable MessageLoggerFix in BetterDiscord’s plugin settings. Capture remains off until you explicitly enable it.
  4. To stop collecting, disable capture. To remove retained events and snapshots, use Clear logs and cache and confirm. Delete any exported JSON separately if desired.

See the official plugin-folder guide for Windows and Linux locations. No automatic install, startup workflow, or deployment is included.
